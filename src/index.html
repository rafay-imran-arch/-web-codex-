Welcome to the documentation of perhaps one of the most easy coding languages out there HTML.
HTML is just a structure you build your website on.
Here are the first few building blocks for html


These are the basic boilerplate tags of HTML, all of the websites will have these!

What's a boilerplate?

Take a look and see if you can guess how the syntax of HTML works


<!DOCTYPE html>
<html lang="en"> 
<!-- The root element; "en" specifies English as the primary language -->
<head>
    <meta charset="UTF-8"> 
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- The title that appears in the browser tab -->
    <title>HTML 5 Boilerplate</title> 
</head>
<body>
</body>
</html>

Did you infer something from this short piece of code?

If you still didn't catch it you can see that these blocks known as html tags follow a pattern. Some of them have a closing/ending tag while some don't
As you can see All have closing tags, while and don't have one. The blocks without an ending tags are knwon as void elements. You can either write them like or with a trailing slash(/) . But wait if you look closely you can also see a tag with text sandwitched in-between the brackets,like this . This is called a comment tag. The browser ignores this tag and all thats written in there! This is used to leave notes for self and other developers so they can better understand what your code does and how it is structured.
